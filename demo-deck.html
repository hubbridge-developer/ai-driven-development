Canlı Demo

Tek cümle, uçtan uca

1
Giriş & prompt. "Let users check if a username is already taken." — tüm girdi bu.
2
Spec Discovery. Qdrant vektör hafızasında ilgili spec'ler + kopya tespiti.
3
Üretim & Doğrulama. Yapılandırılmış spec + deterministik kontroller.
✋
Kapı #1 — Spec onayıİNSAN → git'te versiyonlu spec PR'ı açılır.
4
Code Developer. Etki analizi → planla, yaz, test et, entegrasyon, lint, çalıştır, onar. Koruma kontrolü yıkıcı düzenlemeyi bloklar.
✋
Kapı #2 — Kod onayıİNSAN testler geçmezse PR taslak kalır → kod PR'ı açılır.
✓
Sonuç. Spec + kod + testler + iki PR. Her adım incelenebilir; süre & maliyet canlı.

Soru-Cevap · Cephanelik

Zor sorular

Bozuk/halüsinasyon kodu?
Üç katman: doğrulayıcılar, yıkıcı düzenlemeyi bloklayan koruma, ve testleri gerçekten çalıştırmak. Geçmezse PR taslak.
Copilot'tan farkı?
Copilot editörde üretir. ADD kodun etrafındaki hattı yönetir — spec, inceleme, test, PR, hafıza.
Maliyet?
Aşama başına takip, arayüzde canlı. Ucuz modeli kolay aşamaya, güçlüyü kod aşamasına.
Sağlayıcı kilidi?
LiteLLM. Gemini/Claude/yerel — bir YAML satırı. Ollama, Groq, OpenRouter, Vertex'te çalıştı.
Veri gizliliği?
Vertex ile çağrılar sizin projenizde/bölgenizde, sizin IAM'inizde. Kümeden anahtar çıkmaz.
Mevcut kodu güvenle değiştirir mi?
Etki analizi dosyayı seçer; koruma kontrolü mevcut route/tanımı kaldıran düzenlemeyi reddeder (deterministik).
